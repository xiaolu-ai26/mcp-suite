§ 06 · 常见问题
开通之前，
把这些说清楚。

      

        
购买之后，兑换码从哪里拿？
回到原购买平台的订单交付内容或卖家发送的消息中查收。收到的是兑换码，不是 API key。卖家是否自动发货以该渠道实际设置为准，本页不会根据付款截图开通权限。

        
复制提示词就一定能接通吗？
指令会带上所选客户端需要的地址和凭证，但客户端必须支持远程 MCP 和请求头鉴权，并有相应配置权限。普通聊天页面不一定能安装连接器。保存配置也不等于已接通，需要真实工具调用验证。

        
调用次数有限制吗？
订阅期内无限次调用，同一 key 可在多个客户端共用。AI 客户端本身的账号、会员或模型费用另计。

        
刷新页面之后，key 丢了怎么办？
兑换时只生成并返回一次明文 key，系统不提供原 key 明文找回。已经保存过的，可以在本页重新校验并生成指令；完全丢失请凭订单联系原卖家处理，不要重复购买或公开自己的 key。

        
是不是包含所有企业、所有岗位？
不是。来源正在持续扩展，岗位库只返回实际收录的数据。未收录不代表企业没有招聘；“世界500强目标清单”不等于已经覆盖500家在招岗位。具体条件、状态及可投情况以原公告为准。

        
手机能不能用？
手机可以打开兑换页，但各 Agent 的连接器入口和权限不同。建议在准备使用的电脑上兑换并完成接入；不把电脑版教程直接当作手机版支持证明。
