## 1. 口径(站长 2026-09-19,已写死进代码与工具描述)

| 值 | 判定 |
|---|---|
| `有笔试` | 官方公告/流程页/FAQ/岗位描述明文写了笔试、测评、在线测试、机考、OT 等任一做题环节(测评 = 笔试,不区分) |
| `免笔试` | 官方**公布了完整招聘流程**且流程里**没有**任何笔试/测评环节(如 网申 → 面试 → offer);或官方明文写「免笔试/无笔试/直通面试」 |
| `部分免笔试` | 限定性豁免:优才免笔试、博士研究生免笔试、优秀者可免笔试、部分岗位需笔试。**限定语原样保留在 evidence 里** |
| `未注明` | 官方没公布流程,或读不到。**读不到不等于免笔试** |
