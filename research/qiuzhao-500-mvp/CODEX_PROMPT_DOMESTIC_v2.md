- `industry`

## 任务2：查询功能验证

### 2.1 验证MCP查询端点
用有效API Key测试以下查询（如果没有API Key，跳过并说明）：
- `jobs_search` 按企业名查询（如"字节跳动"、"腾讯"）
- `jobs_search` 按城市查询（如"北京"、"上海"、"深圳"）
- `jobs_search` 按行业查询（如"互联网"、"制造"）
- `jobs_search` 按招聘类型查询（如"校园招聘"、"实习招聘"）
- `jobs_search` 按关键词查询（如"算法工程师"、"产品经理"）
- `jobs_detail` 查询具体岗位详情

### 2.2 验证筛选是否真正生效
- 按行业筛选时，确认返回的岗位industry字段确实匹配
- 按城市筛选时，确认返回的岗位cities字段确实包含该城市
- 按招聘类型筛选时，确认返回的岗位recruitment_type确实匹配
- 如果筛选返回0条，检查是数据问题还是筛选逻辑问题

### 2.3 输出查询验证报告
每个查询输出：查询参数、返回数量、前3条岗位的企业名+岗位名+城市、是否符合预期

## 执行要求

1. **每次修改jobs.json前先备份**：
   ```bash
   cp /var/lib/mcp-suite/jobs.json /var/lib/mcp-suite/jobs.json.bak.codex.$(date +%Y%m%d-%H%M%S)
   ```

2. **修改后必须重启服务**：
   ```bash
   systemctl restart mcp-suite.service
   sleep 3
   curl -s https://savegems.top/qiuzhao/health
   ```

3. **只做归一化和补全，不做删除操作**（除非是完全重复的记录，按detail_url去重）

6. **不伪造**：岗位数据，description必须来自真实招聘页面

7. **每完成一个任务，输出统计结果**（修复了多少条、新增了多少家企业等）
