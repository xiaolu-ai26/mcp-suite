01 / WorkBuddy

  1. 打开 WorkBuddy，进入左侧的连接器管理页；部分版本入口位于“专家 · 技能 · 连接器”。
  2. 点击右上角自定义连接器，打开 MCP 配置。若界面直接提供 URL、传输类型和 Headers 字段，就按页首三项填写。
  3. 若打开的是 JSON 配置文件，在现有 mcpServers 内增加下面的 qiuzhao 项。保留已有连接器，注意前后逗号。
{
  "mcpServers": {
    "qiuzhao": {
      "type": "http",
      "url": "https://savegems.top/qiuzhao/mcp",
      "headers": {"Authorization": "Bearer YOUR_API_KEY"}
    }
  }
}

02 / 豆包工作

  1. 打开并登录豆包工作电脑版，选择本地电脑工作环境。
  2. 点击左侧技能 · 连接器 · 伙伴，右上角选择新建 → 新建自定义连接器。
  3. 服务器名称填写“秋招岗位库”，传输类型选择 HTTP，服务器 URL 填写 https://savegems.top/qiuzhao/mcp。
  4. 在自定义 Headers中新增一行：名称 Authorization，值 Bearer YOUR_API_KEY。替换 key，保留空格。
  5. 保存后，新建工作任务；在输入框下方点击连接器，勾选秋招岗位库，再发送测试问题。

03 / Claude Code

推荐使用环境变量引用，避免把 key 写进项目配置。创建独立配置文件 qiuzhao.mcp.json：

{
  "mcpServers": {
    "qiuzhao": {
      "type": "http",
      "url": "https://savegems.top/qiuzhao/mcp",
      "headers": {"Authorization": "Bearer ${QIUZHAO_API_KEY}"}
    }
  }
}

在自己的终端把 QIUZHAO_API_KEY 设置为兑换所得 key，再运行：

claude --mcp-config ./qiuzhao.mcp.json
# 进入后运行 /mcp，检查 qiuzhao 的三个工具。

也可通过 claude mcp add --transport http 配置请求头；请按官方说明选择配置作用范围。确认工具启用后，用下面三个问题验证。

依据：Claude Code 官方 MCP 文档。已于 2026-09-10 使用 Claude Code 会员连接线上服务，三个工具均完成真实调用。

04 / Cherry Studio

  1. 打开设置 → MCP 服务器，添加服务器，名称填写“秋招岗位库”。
  2. 类型选择 Streamable HTTP，URL 填写 https://savegems.top/qiuzhao/mcp。
  3. 在请求头设置中添加 Authorization: Bearer YOUR_API_KEY，保存并启用。
  4. 在聊天中选择支持工具调用的模型，打开工具/MCP 选择器并启用秋招岗位库。检查工具列表，再发送测试问题。

依据：Cherry Studio 官方 MCP 文档与官方 HTTP 实现。本产品尚未完成 Cherry Studio 实机验收。

连接后的三次测试

  1. “调用 jobs_search 查询岗位，先返回 3 条，保留岗位 id、截止日、状态、原公告链接和数据截至时间。”
  2. “调用 jobs_deadlines，查未来 30 天明确截止的岗位，按截止日倒排；没有结果就如实说明。”
  3. “取刚才一条真实岗位 id，调用 jobs_detail，展示全部岗位条件。”

每次工具调用计 1 次，查询无结果也计次；连接握手、查看工具列表不计次。每天北京时间 00:00 恢复 200 次。

遇到错误

无效 key：检查兑换码与 API key 是否混用、是否漏了 Bearer 和空格。
过期：首发套餐有效至 2026-12-31 当天结束，联系卖家续费。
额度用完：等待次日重置或联系卖家。
没有岗位：放宽专业/届别，换城市，或仅搜关键词；未披露条件不会被自动补全。
